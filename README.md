# cdis-lean

Lean 4 formalization of the probability part of the Mines Paris course CDIS
(Calcul Différentiel, Intégral et Stochastique, Boisgérault et al.), prepared as a
contribution to [ATLAS](https://github.com/facebookresearch/atlas-lean).

Work in progress. See `../reports/REPORT.md` for status.
